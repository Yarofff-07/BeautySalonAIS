
# BeautySalonAIS

**C# WPF · SQLite · Entity Framework**

Інформаційна система управління салоном краси та записом на процедури.

Курсова робота на тему «Проєктування АІС управління салоном краси та записом на процедури».

## Завантажити

1. Відкрийте сторінку Releases і завантажте архів програми, якщо доступна відповідна збірка.
2. Розпакуйте архів у будь-яку папку.
3. Запустіть виконуваний файл BeautySalonAIS.exe.

## Що вміє програма

- Реєстрація та авторизація користувачів.
- Перегляд, додавання, редагування та видалення клієнтів.
- Керування переліком послуг салону та їхньою вартістю.
- Керування інформацією про майстрів.
- Створення нових записів клієнтів на процедури.
- Автоматичне визначення вартості замовлення відповідно до обраної послуги.
- Зміна статусів замовлень.
- Перегляд розкладу записів за допомогою календаря.
- Перегляд замовлень за обраною датою.

## Основні розділи програми

- **Головна** — перегляд записів та створення нових замовлень.
- **Клієнти** — керування інформацією про клієнтів.
- **Послуги** — перегляд і керування послугами салону.
- **Майстри** — керування інформацією про майстрів.
- **Розклад** — календар записів та перегляд замовлень за датами.
- **Налаштування** — налаштування роботи програми.

## Запуск з коду

1. Завантажте або клонуйте репозиторій.
2. Відкрийте файл рішення у Visual Studio.
3. Відновіть необхідні NuGet-пакети.
4. Запустіть проєкт за допомогою клавіші F5.

## База даних

Програма використовує SQLite для зберігання інформації.

Основні таблиці бази даних:

| Таблиця | Призначення |
|---|---|
| Users | Облікові записи користувачів |
| Clients | Інформація про клієнтів |
| Masters | Інформація про майстрів |
| Services | Перелік послуг салону |
| Orders | Записи клієнтів на процедури |

Таблиця Orders містить інформацію про клієнта, майстра, обрану послугу, дату та час запису, загальну вартість і статус замовлення.

## Технології

- C# — основна мова програмування.
- WPF — створення графічного інтерфейсу.
- SQLite — система керування базами даних.
- Entity Framework — робота з даними.
- Visual Studio — середовище розробки.
- Material Design — оформлення інтерфейсу користувача.
